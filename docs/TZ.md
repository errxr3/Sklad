# Техническое задание: складской учёт зеркал

> **О происхождении документа.** Исходный файл `ТЗ_склад_зеркал.docx` к задаче
> приложен не был — он не дошёл до рабочей папки. Этот документ собран из
> постановки задачи заказчика, которая и является главной: там, где исходное
> ТЗ расходится с ней, верна постановка. Когда `.docx` появится, положите его
> рядом (`docs/ТЗ_склад_зеркал.docx`) и сверьте с текстом ниже.

## Суть

Каждое зеркало получает уникальный номер и этикетку со штрихкодом. Сборщик
печатает этикетку, клеит её на зеркало и сканирует — зеркало встаёт на склад.
При отгрузке его сканируют ещё раз — оно списывается. Остаток считается сам.

## Технические рамки

- Python + FastAPI, обычные HTML-страницы с минимумом JavaScript.
- База на этом этапе SQLite (один файл), позже переносится на PostgreSQL.
- Сайт работает на телефоне: крупные кнопки, поле скана всегда в фокусе.
- Сканер работает как клавиатура: вводит код и нажимает Enter.

## Состав версии 0.1 (ядро)

1. Вход по имени сотрудника и PIN-коду, выбор площадки
   (Коминтерна, Учительская).
2. Справочник артикулов из файла `TOP.xlsx`: три листа, артикулы в столбце A.
   При сравнении русская «х» равна латинской «x», лишние пробелы убираются.
3. Экран «Сделал зеркало»: выбор артикула и количества, печать этикеток
   в PDF, приёмка сканом. Зеркалу навсегда присваивается сборщик.
4. Экран «Отгрузка»: скан списывает зеркало.
5. Экран «Остатки»: артикул × площадка.
6. Журнал движений: каждая смена статуса — отдельная запись,
   записи не удаляются.
7. Повторный скан и недопустимые переходы дают понятный отказ на экране.

## Статусы

`Напечатано` → `На складе` → `Отгружено`.

Дополнительно предусмотрены `В пути` и `Списано` — в версии 0.1 не
используются.

## Номер зеркала

Буквы группы плюс 7 цифр. Счётчик общий на все группы.

| Артикул содержит     | Буквы |
|----------------------|-------|
| Zerkalo, bp_Zerkalo  | `Z`   |
| Alum                 | `A`   |
| Ambient              | `AT`  |
| всё остальное        | `X`   |

Пример: `Z0000123`.

## Этикетка

Размер 58 × 40 мм. Сверху чёрная шапка «СКЛАД» с названием площадки,
ниже крупно артикул, под ним штрихкод Code 128 (ширина штриха — 3 точки
принтера с разрешением 203 dpi), под штрихкодом номер цифрами, внизу
сборщик и дата.

> Образец этикетки из исходного PDF к задаче также не дошёл. Этикетка
> свёрстана по описанию выше; сверьте с образцом, когда он появится.
> Текущий вид: `docs/obrazec-etiketki.pdf`.

  и `README.md` (установка и запуск).
